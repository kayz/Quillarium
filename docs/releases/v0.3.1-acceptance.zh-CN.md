# v0.3.1 人工验收清单

本清单对应 [发布流程](../RELEASING.zh-CN.md) 的第 1 步。自动化部分由 `scripts/check.ps1` 和 CI 覆盖；
这里只列需要人在桌面端亲眼确认的行为。每一项写明操作和预期结果，全部勾完才创建 `v0.3.1` tag。

## 0. 准备

- [ ] 复制一个真实的 0.3.0 项目，确保其中有设定图片（`assets/settings/` 非空），只在副本上验收。
- [ ] 本机运行 `pwsh -NoProfile -File scripts/check.ps1`，全部通过。

## 1. 从 0.3.0 升级（风险最高，先做）

- [ ] 打开带旧图片的项目副本，出现"重置旧展示资源"的询问。
- [ ] 选择取消，然后退出应用。检查磁盘：`assets/settings/` 和卡片的 `image` 字段都还在。
- [ ] 重新打开并选择确认：`assets/settings/` 被删除，卡片的 `image` 字段被去掉，展示层开启；
      其余设定、大纲、章正文都没有变化。
- [ ] 打开一个没有旧图片的 0.3.0 项目，不出现询问。

## 2. 新项目默认值

- [ ] 新建项目：节模块关闭，故事树停在章；展示层关闭。
- [ ] 在项目设置中开启节模块，章下面出现节；再关闭，节文件仍留在磁盘上。

## 3. 章与节

- [ ] 节模块开启时，节只能按顺序接受。最后一节确认之前，章正文不变；最后一节确认后，章正文按节顺序写入。
- [ ] 章里已有手写正文时，确认节会被拒绝，手写正文不被覆盖。
- [ ] 定稿后的章不能再用 AI 生成；发布需要输入章名确认，发布后正文不可编辑。

## 4. 世界书与特化

- [ ] 新建一张世界书并特化为人物：卡片 ID 不变，文件移到人物目录，旧文件被删除。
- [ ] 目标类型的必填字段没填时，特化失败，磁盘没有变化。
- [ ] 把人物转回世界书。
- [ ] 正设与世界书互相转换。

## 5. 展示层与配图

- [ ] 开启展示层后卡片显示卡面；关闭后只隐藏外壳，设定内容不变。
- [ ] 上传一张配图：文件出现在 `assets/display/<card-id>/`，卡片 frontmatter 里没有 `image`。
- [ ] 配置生图凭证（与写作用的 AI 配置分开），点击生成：先出现候选预览，确认后才写盘；取消后不留文件。
- [ ] 一张卡有多张图时，轮播可以用鼠标和键盘切换。
- [ ] 卡面设计 Agent 只给出候选，保存模板需要作者确认。

## 6. 专家模式

每一项都要验证两点：取消后磁盘不变，确认后才写入。

- [ ] 评估章正文：只有存在章正文时入口可用；结果包含问题和补设定提案。
- [ ] 整理大纲：只新建当前选中节点的下级；选中章时入口拒绝，不调用模型。
- [ ] 整理世界书：新建世界书，或整段替换已启用世界书的正文。
- [ ] 分析关系：从时态人物关系图进入，针对当前人物给出关系提案。
- [ ] 管理伏笔：从伏笔账本进入；可以同时修改已引用该伏笔的节点上的埋设、回收字段。
- [ ] 整理时间线：只改当前轨道，不新建时间节点。
- [ ] CLI 的专家命令（见 [CLI 文档](../CLI.md)）只评估并打印条数，不写盘。

## 7. 创作助手确认层

- [ ] 设定整理、人物试戏、连续性审阅三个助手：每轮结束后弹出确认层；只勾选部分提案并确认，
      勾选的写入，未勾选的标为已拒绝。
- [ ] 关闭确认层后磁盘不变，该轮可以重新打开确认层。

## 8. 0.3.1 原定范围

- [ ] 从手写章正文抽取设定：正文不变，新卡带指向该正文的 `derived_from`。
- [ ] 拖入一个文本文件：先询问用途；只拖入时不写盘、不调用 AI。
- [ ] 新建空白卡：以禁用的草稿状态出现。
- [ ] 四个界面皮肤可以编辑，预览即时生效但保存后才写盘；"恢复内置"只重置当前皮肤。

## 9. 发布前确认

- [ ] 全部 package manifest 的版本都是 `0.3.1`。
- [ ] 本地 `master` 与 `origin/master` 一致。
- [ ] `v0.3.1` tag 在本地、远端和 GitHub Release 中都不存在。
- [ ] 安装包未签名的提示、全新机器安装、重启、凭据和无障碍检查，按[发布流程](../RELEASING.zh-CN.md)人工完成。
