# 决策记录

只有当一个决策满足下面任一条件时才写成单独的文件：

- 推翻它的代价很大（数据格式、公共接口、状态归属、部署形态）；
- 不写下来，几个月后没人能说清为什么这样做；
- 曾经有过认真的争论，值得留下被否决的选项。

其余决策在 `docs/intent.md` 的“关键决策”里写一行即可。

文件命名沿用本目录已有的方式；新目录用 `NNNN-简短标题.md`。内容保持在一页以内：

```markdown
# NNNN 标题

状态：已采纳 | 已取代（见 NNNN）

## 背景

## 决策

## 后果（包括放弃了什么）
```

被取代的决策不要删除，改状态并链接到新决策。
