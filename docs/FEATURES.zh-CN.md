# 功能清单

验收底账。日期 2026-11-08。产品含义以 [intent](intent.md) 为准，模块所有权以
[ADR-work-audiences](adr/ADR-work-audiences.md) 为准。物品和等级是作者已确认的设定实体。除此之外，本清单不另造文档类型。标成「待规格」的条目不实现、不测试、不算这一版验收。地图画布和编剧留在待规格。

状态：

| 状态   | 含义                                                                     |
| ------ | ------------------------------------------------------------------------ |
| 已有   | 当前代码已有对应行为。后续改动不得把它做丢。                             |
| 增强   | 已有一部分。条目写的是还要补上的行为。                                   |
| 新增   | 现在没有。做成之后用本条目验收。                                         |
| 待规格 | 这一版不实现、不测试、不算验收。有的只有名字，有的规格已记下但明确推后。 |

新增的模块是用户权限与设定。世界书、结构树、Agent、展示层、导入导出都增强。拆书和短剧导出不单独成模块。五档名称和开关见 [先补齐模板](PLAN-templates.zh-CN.md)。作品里的主页面和这一版的 Windows 外观见下面的「界面」。

## 用户权限与设定

管两件事：这部作品允许使用哪些层，以及作者本机上的界面设定。能力记在新建作品上，不记在账号上。不为旧作品做兼容。模型、提示词和密钥归 Agent。

| CAP-2 | 预设五档：传统作家、AI 写手、AI 编剧、OC 人、AI 原住民。                           | 新增 |
| CAP-3 | 交给用户时新建作品并完成问卷。不为旧作品补能力记录，也不做设定迁移。               | 新增 |

## 界面

首页是作品资料库，用来打开或新建作品。进入一部作品之后，不再使用「规划」和写作侧栏这两套导航，只留世界书和写作两个主页面。这一版写作页不放剧本设定、剧本资产和分镜。它们以后也不是第三主页面，并仍受 CAP-7 控制。

五档共用这两页和其中的标签。作家与 OC 的差别只在进门后的第一页。OC 不另做功能。展示层打开时能挂图和做卡片的范围见 DP-9。节、展示、生图仍由 CAP-5、CAP-6 和 DP-8 决定。

| UI-2 | 作家进入后第一页是写作。作家指传统作家、AI 写手、AI 编剧。                                                                                                                                                                                                                  | 新增 |

## 世界书

世界书是设定事实的入口。基础条目承接世界观和常识。事件、人物、地点、物品、组织、等级是挂在世界书上的设定实体。界面上的「组织」使用现有势力文件，不另建文档类型。伏笔不留在这里，显性地转到写作，见 FS-1。

| 编号  | 功能点                                                                                                                                                                                               | 状态 |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| WB-1  | 可以新建世界书，也可以新建禁用的空白草稿，再手填。                                                                                                                                                   | 已有 |
| WB-2  | 标签、触发词、来源和启用状态可以编辑；正文用 Markdown，不执行原始 HTML。                                                                                                                             | 已有 |
| WB-3  | 从章正文抽出的新卡带 `derived_from`，指向那篇正文。抽取不改正文。                                                                                                                                    | 已有 |
| WB-12 | 基础条目可以由导入、手写或对话产生。系统负责保存、检索和扩库。对话、导入、拆书和扩库产生的条目先是提案，可以带建议类型：基础条目、人物、地点、事件、物品或组织。作者确认时可以改类型。未确认不写入。 | 增强 |
| WB-13 | 世界观和常识不单独成页，是世界书条目上作者自己添加的字段。不预置世界观模板。                                                                                                                         | 新增 |

## 写作

写作页承接原来的结构树。作品结构是一棵树，伏笔跨在树外，节是打开节与生文之后才有的独立写作面。

### 结构树

| 编号 | 功能点                                                                                                                                                                                                 | 状态 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| ST-1 | 树根是作品名称、简介和作品属性。其下是卷、篇、幕、章，并且必须是树。新作品默认只显示卷和章。篇和幕在写作设置里打开，默认关闭。关掉只隐藏，不删文件。每一层都可以写大纲或细纲。节不是这棵树上的发布层。 | 增强 |
| ST-2 | 关闭篇或幕时不删除文件。章显示在最近的仍开启的父级下面。                                                                                                                                               | 已有 |

### 章

| 编号 | 功能点                                                               | 状态 |
| ---- | -------------------------------------------------------------------- | ---- |
| ST-3 | 一章包含章纲和章正文。节关掉时，章是最小文字单位，正文由作者手写。   | 增强 |
| ST-4 | 章正文依次是草稿、定稿、已发布。已发布不可编辑。发布要作者确认章名。 | 已有 |
| ST-5 | 定稿之后不能再对这一章做 AI 生文。                                   | 已有 |

### 节

| 编号  | 功能点                                                                                                                                                                                                                                                                                                                                                                                                   | 状态   |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| ST-6  | 只有这部作品打开节与生文时，章下才出现节。节是章的细分，生成使用独立界面。                                                                                                                                                                                                                                                                                                                               | 增强   |
| ST-7  | 每一节先写情节，也就是本节要完成的事，再拼装提示词、选择生文模型并生成。一节的默认目标大约 1000 字，章的建议范围大约 3000 到 6000 字。作者可以改目标，也可以保存更短或更长的正文。                                                                                                                                                                                                                       | 增强   |
| ST-8  | 章内分为多节，每节单独生文。各节可以轮选、删除、修改、定稿。全部节都定稿后，按节序合并成这一章的正文草稿，不另成新章。合并写入的是快照。之后再改某一节，章正文不自动跟着变，需要再合并一次。章已经定稿或已发布时，拒绝再次合并。                                                                                                                                                                         | 新增   |
| ST-9  | 章里已有手写正文时，拒绝用节覆盖。                                                                                                                                                                                                                                                                                                                                                                       | 已有   |
| ST-10 | 生文提示词是多段结构。一段是一份放进这次提示词的材料。显示时每段给出简介、来源和字数。简介用来源标题和它在提示词里的作用。作者可以上下拖动改变顺序，展开后修改这一次的文字。修改不写回世界书、参考资料或大纲。发送顺序就是作者拖动后的顺序。任何作品文档都可以加为一段。做法借鉴 SillyTavern 的分段编辑，不执行它的宏，也不使用注入深度。                                                                | 新增   |
| ST-11 | AI 参考资料包括冲突、戏剧理论、文风和写作指导，权限与节相同。可以用导入、对话或手写加入。它进入提示词的方式与世界书相同，见 ST-10 和 ST-15。它不是 IO-2 那种只归档、不进提示词的参考资料。                                                                                                                                                                                                               | 新增   |
| ST-15 | 提示词模板只保存段的种类和默认顺序，不保存某一次填好的正文。模板放在该作品目录里，可以有多份。模型不修改模板。还没手工排过的节使用作品当前模板，由模型按该节纲要填入具体材料，同一种类可以有多段。已经拖动或增删过的节沿用那份顺序，下次只刷新各段内容。作者可以把当前顺序另存为模板。默认顺序是写作要求、大纲、本节细纲、世界书、参考资料、伏笔、附近章节。节纲要为空时，只放写作要求、大纲和本节细纲。 | 新增   |
| ST-12 | 剧本设定包括剧集长度，以及剧集和章的关系。有这部作品的通用设置，也有当前这一集的设置。这一版不做。                                                                                                                                                                                                                                                                                                       | 待规格 |
| ST-13 | 剧本资产包括人物、服装、建筑、画风等。本工具只产生资产提示词；生图和生视频由其他工具完成。每条资产提示词带上该资产的种子 ID，收回结果时用这个 ID 对回本地资产。这一版不做。                                                                                                                                                                                                                              | 待规格 |
| ST-14 | 分镜是节的再拆分。一节大约 1000 字，对应约 1–2 分钟镜头；AI 生视频一般只有 5–15 秒，所以一节再切成多个分镜。每个分镜对应一次视频生成，并保持前后顺序。交给外部工具的是分镜提示词，不处理视频。这一版不做。                                                                                                                                                                                               | 待规格 |

### 伏笔

| 编号 | 功能点                                                                                                                                                                     | 状态 |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| FS-1 | 伏笔在写作页管理，不放进篇章树。一条伏笔包括被掩盖的真相、埋设位置和回收位置。埋设和回收位置选写作树上的卷、篇、幕或章，不用时间线节点当位置。一条伏笔可以跨任意这些层级。 | 增强 |
| FS-2 | 管理结果先是提案。作者确认后才写入；取消则磁盘不变。                                                                                                                       | 已有 |
| FS-3 | 写到相关范围时，满足条件的伏笔以可解释的提醒进入上下文。                                                                                                                   | 已有 |

## Agent

按场景持有模型、提示词和一次运行。写入作品的结果都是提案。

### 自己的界面

| 编号 | 功能点                                                                    | 状态 |
| ---- | ------------------------------------------------------------------------- | ---- |
| AG-1 | Agent 有单独界面，能查看和修改 Provider、模型选择和公共提示词。           | 增强 |
| AG-2 | 密钥留在本机配置，不进入作品目录。                                        | 已有 |
| AG-3 | 作品选用的 WritingPreset 决定这一部作品的模型覆盖、提示词栈和上下文策略。 | 已有 |

### 运行边界

| AG-6 | 节能力关掉时，Agent 不提供生文。OC 人同时不提供生图。拆书、扩库、整理、检查和伏笔提醒仍可调用相应模型。传统作家关闭生文，这几项仍可用。 | 增强 |

## 导入导出

外部内容进作品，或已接受的内容离开作品。适配器不定义作品内部的文档类型。

### 进入作品

| 编号 | 功能点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | 状态 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| IO-1 | 拖入文本或 Markdown 时先选择用途。只拖入不写盘，也不调用模型。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | 已有 |
| IO-2 | 选参考资料时，按 UTF-8 归档，不调用模型，不保留外部绝对路径。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | 已有 |
| IO-3 | 选设定导入时，进入需作者审阅的提案。未确认不写卡。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | 已有 |
| IO-4 | 从 CCv3 JSON 或 PNG 创建故事结构为空的新项目。带入的设定是待审草稿。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | 已有 |
| IO-9 | 拆书从世界书的导入进入，不占主页面，也没有单独阅读器。作者放入文本后，模型一次列出世界书提案和建议类型；作者勾选、改类型，确认后写入。不先进入多轮对话。先询问是否把正文也导入，默认不导入。不导入时，原文只留在导入记录里供核对，不进写作树，也不自动进入提示词。选择导入时，正文直接写成章草稿，不另做章节预览，不自动写大纲或节，不在导入记录里再留一份全文。单独成行的「第…卷」「第…章」和对应的 Markdown 标题建成卷和章，其余标题留在章正文里。新章接在已有内容后面，不覆盖已有章。没有卷名的章归入第一卷；还没有卷时新建一卷。原文里的篇、幕不单独建层。这些章按已有正文对待，节不能覆盖。 | 新增 |
